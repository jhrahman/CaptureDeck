# Contributing to CaptureDeck

Contributions are welcome: bug reports, ideas, fixes, features and better documentation.

## Before you start

- **Found a bug?** [Open an issue](https://github.com/jhrahman/CaptureDeck/issues). Say what you did, what you expected and what happened, with your macOS version. Remove anything private from screenshots and recordings first.
- **Planning something big?** Open an issue first, so we can agree on the approach before you spend time on it.

## Making a change

1. Fork the repository and create a branch.
2. Make your change, and add or update tests for it.
3. Run the tests and build the app:

   ```sh
   ./scripts/test.sh
   ./scripts/build-app.sh
   ```

4. Update the [User Guide](USER-GUIDE.md) if people will see the difference.
5. Open a pull request that explains what changed and why.

Keep pull requests focused on one thing. Follow the style of the code around your change, and avoid adding third-party packages without discussing it first.
